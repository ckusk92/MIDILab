# Security Policy

## Reporting a vulnerability

Please do **not** report suspected security vulnerabilities through a public GitHub issue.

The preferred reporting method is GitHub's **private vulnerability reporting** feature on this repository. If the feature is enabled, use the repository's Security area and choose **Report a vulnerability**.

If private vulnerability reporting is temporarily unavailable, contact the repository owner privately through a contact method published on their GitHub profile and include only the minimum information needed to establish a private reporting channel.

When reporting a vulnerability, please include when possible:

- A description of the issue
- Steps to reproduce it
- Affected MIDILab version(s)
- Potential impact
- Any suggested mitigation or patch

Please allow reasonable time for investigation and remediation before public disclosure.

## Supported versions

MIDILab is currently an early-stage project. Security fixes will generally target the latest release rather than maintaining long-term support branches for older versions.
